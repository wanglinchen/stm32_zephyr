# 阿波罗 V2（STM32F429IGT6）模块 - 驱动对照表

> 依据：`docs/hardware/`（正点原子阿波罗 V2 资料集）
> - 引脚第一来源：`pinmap/阿波罗V2 STM32F429开发板IO引脚分配表.xlsx`（已导出 `logs/pinmap.txt`）
> - 核心板：`sch/STM32F429_CORE_V2.pdf`（确认 SoC = **STM32F429IGT6**，176 脚，1 MB Flash，HSE 25 MHz，LSE 32.768 kHz）
> - 底板：`sch/DNF429P_F767P_H743P V2.6.pdf`（5 页；文字层错位，用 PyMuPDF 按关键字裁切放大后目视读连接）
>
> 目标：在 Zephyr 4.5 上把板上各模块落到驱动层，做到「能编译、能在现场自检、缺口写清楚」。

## 0. 一句话结论

| 维度 | 现状 |
| --- | --- |
| 构建 | **通过**：`build/apollo_f429/zephyr/zephyr.elf`，FLASH 119,884 B / 1 MB（11.43%），RAM 22,720 B / 192 KB（11.56%），SDRAM1 750 KB / 32 MB（LTDC 帧缓冲） |
| 上游现成驱动直接复用 | SDRAM(FMC)、LTDC、PCF8574、QMI8658A、XPT2046、SPI NOR(W25Q256)、SPI/SPI-bitbang、I2C、UART、RTC、ADC、DAC、GPIO Keys、Flash 内部控制器 |
| out-of-tree 自写驱动 | NAND `MT29F4G08`、编解码 `ES8388`、光感/接近 `AP3216C`、单总线 `DHT11`、红外 `NEC` |
| 上游无驱动 / 无节点 / 未启用 | 以太网 YT8512C(RMII)、TF 卡(SDIO)、DCMI+OV5640、SAI1 音频数据通路、SPA06-003、DS18B20、NRF24L01、8080 并口屏（默认关闭）、CAN1（与 USB 跳线冲突，默认关闭） |
| 自检手段 | 串口 shell 命令 `devices`（`app/src/app_devices.c`），逐项打印 `device_is_ready()` |

**注意口径**：本表「可用」= 驱动已实例化并能通过编译期/链接期检查；**除特别标注外均未上板实测**，寄存器初值、时序参数按芯片手册与例程填写，需现场用 `devices` + 实际读写复核。

### 2.1 踩过的坑（都已修掉，后续维护直接参考）

1. **SOC 未选中（致命）**：`hwm_v2.cmake` 会用 `osource <board_dir>/Kconfig.<BOARD>`，out-of-tree 板必须自带 `Kconfig.apollo_f429` 定义 `config BOARD_APOLLO_F429` 并 `select SOC_STM32F429XX`；缺它时 `.config` 里没有 `CONFIG_SOC*`，编译直接失败。
2. **out-of-tree 模块不能声明 `kconfig:`**：作为 `ZEPHYR_EXTRA_MODULES` 加入且带 `kconfig:` 会触发 Kconfig `RecursionError`。因此驱动不设 Kconfig 开关，改为无条件编译 + `DT_INST_FOREACH_STATUS_OKAY` 自动实例化。
3. **multiple definition（最耗时）**：增量 build 目录在 CMake 重配后可能把同一库重复加入 `LINK_LIBRARIES`，连 `hal_stm32` 都会重复。已被 `drivers/CMakeLists.txt` 的单一幂等库缓解；仍出现时用 `.\scripts\build.ps1 -Pristine`。
4. **HAL NAND 不在 HAL 构建列表**：Zephyr HAL 只编 `stm32f4xx_hal_sdram.c` + `stm32f4xx_ll_fmc.c`，`stm32f4xx_hal_nand.c` 需在驱动 CMakeLists 显式加入（会有对象路径 >250 字符的 CMake 警告，可忽略）。
5. **HAL NAND API**：`Instance = FMC_Bank2_3`；`Init.NandBank = FMC_NAND_BANK2`（值 0x10，是位标志）；无 `SpareAreaSize` 字段；`get_parameters` 返回 `const struct flash_parameters *`。
6. **LTDC 只支持 RGB888**：`display_stm32_ltdc.c` 对非 `PANEL_PIXEL_FORMAT_RGB_888`（枚举值 = 1）有 `#error`；且 PLLSAI 的 `div-r` 受 binding 限制，最终用 `mul-n=384/div-r=6/post-div-r=2` 得 32 MHz 像素时钟。
7. **F4 ADC 需要先开父节点**：`adc123_common`（`st,stm32-adc`）在 dtsi 里默认 `status="disabled"`，只开 `&adc1` 时 `DT_HAS_ST_STM32_ADC_ENABLED=n`，`CONFIG_ADC_STM32` 被强置 `n`；两者都开并补 `st,adc-prescaler=<4>` 才通过 binding 校验。
8. **脚本编码**：`scripts/*.ps1` 含中文，必须 UTF-8 **with BOM**，否则 PowerShell 5.1 按 ANSI 解码报 `string missing terminator`；`env.ps1` 用 `$MyInvocation.MyCommand.Path` 反推根目录（dot-source 时 5.1 下 `$PSScriptRoot` 可能为空）。

## 3. 现场自检

串口：USART1（CH340，115200 8N1）。进入 shell 后：

```
uart:~$ devices
模块          设备名                状态
uart1         usart@40011000        OK
...
adc1          adc@40012000          OK
nand          nand@70000000         OK
...
```

判定口径：
- `OK` = 设备对象存在且 `device_is_ready()` 通过（驱动初始化成功）。
- `FAIL` = 设备存在但 init 返回错误（多为时钟/引脚/总线未通）。
- 命令里**没有出现**的模块 = 该节点未启用或驱动未实例化（对应本表 ⚪/⛔ 行）。

## 4. 构建 / 烧录

```powershell
# 每个新会话一次
. .\scripts\env.ps1

# 默认构建 apollo_f429（脚本自动附加 BOARD_ROOT 与 ZEPHYR_EXTRA_MODULES）
.\scripts\build.ps1
.\scripts\build.ps1 -Pristine          # 出现 multiple definition 时用
.\scripts\build.ps1 -Board stm32f429i_disc1   # 对照官方板

# 烧录（pyocd，--target=stm32f429xi；会覆盖板内现有固件）
.\scripts\flash.ps1
```

```powershell
west build --% -b apollo_f429 -d build\apollo_f429 app -- -DBOARD_ROOT=C:/Users/Cwl/Desktop/stm32-zephyr -DZEPHYR_EXTRA_MODULES=C:/Users/Cwl/Desktop/stm32-zephyr/modules/apollo_f429
```

## 5. 待办与已知缺口

| 优先级 | 事项 | 说明 |
| --- | --- | --- |
| 高 | 上板验证 | 目前全部结论来自编译/链接与手册，未用 ST-Link 实测。建议先跑 `devices`，再逐项读写（NAND 读 ID、W25Q256 JEDEC ID、QMI8658A WHO_AM_I、AP3216C、XPT2046 触摸坐标） |
| 高 | `flash0` / `sdram1` 设备对象缺失 | 两个节点都已 okay，但 `DEVICE_DT_GET` 在链接期找不到设备对象；需查上游 F4 flash/memc 实例化路径。影响：内部 flash 上的 NVS/settings、SDRAM 运行期自检 |
| 中 | ES8388 + SAI1 数据通路 | 寄存器层已就绪，缺 I2S 时钟与 DMA 配置；`sai1` 节点需启用并分配 DMA 通道 |
| 中 | 以太网 YT8512C | 需确定 PHY 地址、把 PCF8574 P7 接入复位、评估 `CONFIG_NET` 的 RAM 占用 |
| 中 | TF 卡 / 摄像头 | F4 dtsi 缺 `sdmmc`、`dcmi` 节点，需自建节点（含 IRQ/时钟）；SCCB 还缺 `i2c-bitbang` 绑定 |
| 低 | SPA06-003 / DS18B20 / NRF24L01 / RS485 方向封装 | 前者缺手册，后三者可按现有总线自写 |
| 低 | 8080 并口屏 / CAN1 | 默认关闭，分别因引脚与 USB 冲突；需要时手工开启并校准参数 |
