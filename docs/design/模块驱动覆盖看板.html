缺口与下一步

P0 上板验证全部结论来自编译/链接与手册；先用串口 devices 看设备就绪，再逐项读写 ID（NAND、W25Q256、QMI8658A、AP3216C、XPT2046）。
P0 flash0 / sdram1节点都 okay，但 DEVICE_DT_GET 链接期缺设备对象，影响内部 flash 上的 NVS 与 SDRAM 自检。

P1 以太网确定 PHY 地址、把 PCF8574 P7 作复位、评估 CONFIG_NET 的 RAM 占用。
P1 存储卡 / 相机F4 dtsi 缺 sdmmc、dcmi 节点，需自建；SCCB 还缺 i2c-bitbang 绑定。
P2 其余SPA06-003（缺手册）、DS18B20、NRF24L01、RS485 方向封装、8080 屏参数校准、CAN1 引脚复用。
